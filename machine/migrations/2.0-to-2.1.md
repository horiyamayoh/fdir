
# FDIR 2.0 to 2.1 migration boundary

FDIR 2.1 makes assertion-first semantics, exhaustive accounting, profile-scoped completeness, and evidence-backed equivalence mandatory. A 2.0 object that stores substantive content directly on an information unit must be migrated into assertions. A migration must preserve the original artifact and selectors, emit diagnostics for information that cannot be mapped, and must not infer `equivalent` from successful parsing alone.
