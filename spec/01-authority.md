
# 1. Authority, conformance, and projections

A conforming FDIR 2.1 implementation preserves the authority hierarchy. The logical model and pinned generator define the core contract. Registries define requirements, tests, profiles, capabilities, and decisions. Prose explains intent. Generated review artifacts are useful but non-canonical.

Omitting a generated PDF, DOCX, PNG, SVG, index, or report is not loss of canonical information when the source and deterministic generator remain. Publishing such a projection requires provenance that identifies the baseline version, generator version, and source digest.
